# 🎸 Banda de Rock Boca de Lobo

Site oficial da banda fictícia "Boca de Lobo", criado como projeto de prática para desenvolvimento web. O objetivo é apresentar informações sobre a banda, seus integrantes, discografia e agenda de shows, com um visual moderno e responsivo.

---

## 📌 Funcionalidades

- Página inicial com apresentação da banda
- Seção de integrantes com fotos e descrições
- Galeria de álbuns e músicas
- Agenda de shows e eventos
- Formulário de contato

---

## 🧰 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
